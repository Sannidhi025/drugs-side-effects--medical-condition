🧠 Project Overview
This project explores the relationship between pharmaceutical drugs, their reported side effects, and associated medical conditions. Leveraging real-world medical datasets, it applies data preprocessing, exploratory analysis, and machine learning techniques to uncover insights and build predictive models. The goal is to support healthcare professionals and patients by providing a data-driven perspective on drug safety and efficacy.

📊 Key Objectives
Analyze patterns of side effects across different drugs and patient demographics.

Identify the most commonly reported side effects and their severity levels.

Predict potential side effects based on drug properties and user profiles.

Explore the link between medical conditions and drug usage.

🧹 Workflow Summary
Data Preprocessing: Cleaning, normalization, missing value handling, and feature engineering.

Exploratory Data Analysis (EDA): Visualizing trends, distributions, and relationships in the dataset.

Modeling: Applying classification and NLP models to predict side effects and extract insights.

Evaluation: Assessing model performance using metrics like accuracy, F1 score, and ROC-AUC.

Results: Identified high-risk drugs, sensitive patient groups, and effective predictors.

Future Scope: Enhanced modeling with deep learning and integration with clinical data systems.

🛠️ Tech Stack
Languages: Python

Libraries: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, NLTK / SpaCy

Tools: Jupyter Notebook, Git, GitHub
